# 🧪 Practical-First Learning Model

For every major subject:

**Learn → Implement → Lab → Task → Mini Project → Attack/Test → Fix → Retest → Report → Explain**

The goal is not simply to finish theory.

> **Understand → Build → Break → Fix → Defend**
